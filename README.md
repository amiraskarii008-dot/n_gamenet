# CafeLoop — کافه‌لوپ

> **Turn one-time visitors into regulars.**
> مشتری‌های یک‌بار مصرف کافه را به مشتری تکراری تبدیل کن — و درآمدش را اندازه بگیر.

این مخزن، وب‌سایت معرفی و **دموی محصول** CafeLoop است: یک وب‌سایت استاتیک با HTML، CSS و JavaScript خالص
(بدون فریم‌ورک، بدون بیلد، بدون وابستگی اجباری).

---

## ایده در یک پاراگراف

نسخه‌ی اول این ایده یک «Digital OS برای کافه» بود: QR + AI + NFC + Wallet + CRM + …
جذاب، اما Feature-heavy و Solution-first. این نسخه با همان هسته ساخته شده است، ولی **دلیل خرید عوض شده**:

| | نسخه قبلی | CafeLoop |
|---|---|---|
| وعده | «همه‌چیز برای کافه، در یک سیستم» | «مشتری‌هایت را برمی‌گردانیم و درآمدش را می‌سنجیم» |
| واحد سنجش | تعداد قابلیت | **Repeat Rate** (نرخ بازگشت مشتری) |
| محصول | Digital OS | سیستم بازگشت مشتری (Retention System) |

منوی دیجیتال فقط **دروازه‌ی ورود** است؛ محصول واقعی، لایه‌ی رابطه با مشتری است.

## ساختار فایل‌ها

```text
.
├── index.html                # لندینگ
├── mvp.html                  # برنامه‌ی یک‌صفحه‌ای مشتری و داشبورد مدیریت
├── how-it-works.html
├── demo.html                 # داشبورد کافه (دمو)
├── customer.html             # سمت مشتری (دمو)
├── pricing.html
├── roadmap.html
├── contact.html
├── 404.html
└── assets
    ├── css/style.css         # دیزاین‌سیستم سایت
    ├── css/mvp.css           # رابط شیشه‌ای، راست‌چین و واکنش‌گرای فضای مشتری و مدیریت
    ├── img/logo.svg          # لوگو (فنجان + حلقه)
    └── js
        ├── mvp.js            # گردش‌کار مشتری و مدیریت، سفارش آزمایشی و ذخیره‌ی محلی نسخه‌بندی‌شده
        ├── main.js           # ناوبری، انیمیشن اسکرول، شمارنده‌ها، FAQ، توست
        ├── data.js           # داده‌ی نمونه‌ی دمو (کافه فرضی Cafe Noir)
        ├── dashboard.js      # موتور داشبورد: KPI، نمودارهای Canvas، جدول، کمپین
        ├── customer.js       # موبایل تعاملی مشتری + امتیاز + پیشنهاد + QR دمو
        └── contact.js        # اعتبارسنجی فرم (شماره با رقم فارسی هم پذیرفته می‌شود)
```

## اجرا

هیچ ابزار بیلدی لازم نیست. کافی است فایل‌ها را با یک وب‌سرور ساده سرو کنی:

```bash
python3 -m http.server 8080
# سپس: http://localhost:8080
```

> باز کردن مستقیم فایل‌ها با `file://` هم کار می‌کند، اما برای بخش‌هایی مثل `localStorage` و
> خروجی CSV بهتر است از یک وب‌سرور استفاده کنی.

## اجرای نسخه‌ی نمایشی روی GitHub Pages

1. به **Settings → Pages** مخزن برو.
2. در بخش *Branch*، برنچ `arena/01a0fdc8-n-gamenet` (یا `main` پس از مرج) را انتخاب کن و پوشه‌ی `/ (root)` را ست کن.
3. صفحه‌ی `index.html` به‌صورت سایت بالا می‌آید.

## چه چیزی در دمو واقعاً کار می‌کند

- جست‌وجو، فیلتر وضعیت و مرتب‌سازی جدول مشتریان
- محاسبه‌ی Priority Score برای اولویت‌بندی تماس
- **Campaign Builder**: انتخاب گروه → پیش‌نمایش پیام با متغیرها → اجرا → نتیجه‌ی ساخته‌شده + افزودن به تاریخچه
- نمودارهای Canvas (روند نرخ بازگشت، ترافیک ساعتی) با رسم مجدد در تغییر اندازه‌ی صفحه
- خروجی CSV از لیست فیلترشده مشتریان
- برنامه‌ی یک‌صفحه‌ای MVP مشتری/مدیریت: سوییچ محیط، جست‌وجو و فیلتر منو، شخصی‌سازی محصول، سبد، پیشنهاد/امتیاز، سفارش آزمایشی، پیگیری و سفارش مجدد
- داشبورد مدیریت قابل استفاده: ساخت/ویرایش/حذف و فعال‌سازی محصول، مشتری و پیشنهاد؛ تغییر وضعیت سفارش؛ تنظیم نام کافه و منطق امتیاز؛ افزودن اختیاری داده‌ی نمونه و دانلود پشتیبان JSON
- پروفایل مشتری و امتیاز از صفر شروع می‌شوند؛ سفارش، مشتری یا پیشنهاد ساختگی به‌طور پیش‌فرض نمایش داده نمی‌شود. منوی نمونه فقط کاتالوگ آزمایشی است.
- موبایل مشتری در صفحه‌ی معرفی: افزودن به سفارش، عضویت، امتیاز، آفر و پاک‌کردن داده‌ی دمو
- فرم تماس با اعتبارسنجی و پیام موفقیت

> ⚠️ **این نسخه یک پروتوتایپ سمت مرورگر است.** دیتای قدیمی MVP خوانده نمی‌شود؛ پروفایل، سفارش، امتیاز، علاقه‌مندی، پیشنهاد و تغییرهای مدیریتی تازه فقط در `localStorage` همان دستگاه و فضای نسخه‌بندی‌شده‌ی `cafeloop-mvp-workspace-v2` می‌مانند. داده‌ی نمونه فقط با انتخاب مدیر اضافه می‌شود. سفارش/پرداخت به کافه ارسال نمی‌شود و پشتیبان JSON نیز فقط داده‌های همان مرورگر را صادر می‌کند.

## قدم بعدی (طبق ۷ Day Startup)

1. این دمو را به ۱۰ تا ۲۰ کافه نشان بده.
2. بپرس: «ماه قبل چند درصد مشتری‌هاتون برگشتند؟» و «برای برگرداندنشان ماهانه پول می‌دید؟»
3. با یک Concierge MVP (گوگل‌شیت + اتوماسیون) اولین کمپین را اجرا کن.
4. عدد را اندازه بگیر: چند نفر هدف، چند نفر برگشت، چند تومان فروش.
5. اگر پول آمد → بساز. اگر نیامد → به‌جای افزودن قابلیت، دلیل «نه» را بفهم.
