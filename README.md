# CafeLoop — کافه‌لوپ

> **Turn one-time visitors into regulars.**
> مشتری‌های یک‌بار مصرف کافه را به مشتری تکراری تبدیل کن — و درآمدش را اندازه بگیر.

این مخزن، وب‌سایت معرفی و **دموی محصول** CafeLoop است: یک وب‌سایت استاتیک با HTML، CSS و JavaScript خالص
(بدون فریم‌ورک، بدون بیلد، بدون وابستگی اجباری).

> 🚀 **دکمه‌ی MVP:** در هدر و بخش اول `index.html` دکمه‌ای شیشه‌ای با برچسب «باز کردن MVP مشتری» گذاشته شده؛
> با یک کلیک `mvp.html` — همان برنامه‌ی اصلیِ سمت مشتری که با HTML/CSS/JS ساخته شده — تمام‌صفحه باز می‌شود
> و همه‌ی بخش‌های مشتری (منو، سفارش، سرویس میز، امتیاز، پیشنهاد شخصی، پروفایل) را با منوهای شیشه‌ای و گزینه‌های پیشرفته بالا می‌آورد.

---

## ایده در یک پاراگراف

نسخه‌ی اول این ایده یک «Digital OS برای کافه» بود: QR + AI + NFC + Wallet + CRM + …
جذاب، اما Feature-heavy و Solution-first. این نسخه با همان هسته ساخته شده است، ولی **دلیل خرید عوض شده**:

| | نسخه قبلی | CafeLoop |
|---|---|---|
| وعده | «همه‌چیز برای کافه، در یک سیستم» | «مشتری‌هایت را برمی‌گردانیم و درآمدش را می‌سنجیم» |
| واحد سنجش | تعداد قابلیت | **Repeat Rate** (نرخ بازگشت مشتری) |
| محصول | Digital OS | سیستم بازگشت مشتری (Retention System) |

منوی دیجیتال فقط **دروازه‌ی ورود** است؛ محصول واقعی، لایه‌ی رابطه با مشتری است.

    ├── site.webmanifest      # متادیتای PWA برای mvp.html

    └── js

        ├── customer.js       # موبایل تعاملی مشتری + امتیاز + پیشنهاد + QR دمو
        ├── mvp-data.js       # داده‌ی منو، گزینه‌ها، سطوح وفاداری، پاداش‌ها و آفرهای اپ MVP
        ├── mvp.js            # موتور اپ مشتری: سبد، سفارش، امتیاز، پیشنهاد، تنظیمات پیشرفته
        └── contact.js        # اعتبارسنجی فرم (شماره با رقم فارسی هم پذیرفته می‌شود)

## اجرا

هیچ ابزار بیلدی لازم نیست. کافی است فایل‌ها را با یک وب‌سرور ساده سرو کنی:

```bash
python3 -m http.server 8080
# سپس: http://localhost:8080
```

- لندینگ و صفحات معرفی: `http://localhost:8080/index.html` → دکمه‌ی **🚀 باز کردن MVP مشتری**
- خودِ اپ MVP: `http://localhost:8080/mvp.html` (نسخه‌ی فول‌اسکرین سمت مشتری)
- شبیه‌سازی اسکن QR یک میز: `http://localhost:8080/mvp.html?table=12#menu`

> باز کردن مستقیم فایل‌ها با `file://` هم کار می‌کند، اما برای بخش‌هایی مثل `localStorage` و
> خروجی CSV بهتر است از یک وب‌سرور استفاده کنی.

## چه چیزی در دمو واقعاً کار می‌کند

- جست‌وجو، فیلتر وضعیت و مرتب‌سازی جدول مشتریان
- محاسبه‌ی Priority Score برای اولویت‌بندی تماس
- **Campaign Builder**: انتخاب گروه → پیش‌نمایش پیام با متغیرها → اجرا → نتیجه‌ی ساخته‌شده + افزودن به تاریخچه
- نمودارهای Canvas (روند نرخ بازگشت، ترافیک ساعتی) با رسم مجدد در تغییر اندازه‌ی صفحه
- خروجی CSV از لیست فیلترشده مشتریان
- موبایل مشتری: افزودن به سفارش، عضویت، امتیاز، آفر، پاک‌کردن داده‌ی دمو

### در `mvp.html` (اپلیکیشن مشتری) این‌ها واقعاً کار می‌کند
- **منوی دیجیتال:** ۲۹ آیتم در ۵ دسته، جست‌وجو، فیلتر رژیم/آلرژن، سقف قیمت، ۵ حالت مرتب‌سازی، نشان‌کردن علاقه‌مندی
- **گزینه‌های سفارش:** سایز، شیر (شیر گیاهی)، میزان شکر، دما، extras با قیمت، یادداشت برای بار، تعداد، «پیش‌فرض کن»
- **سبد و ثبت سفارش:** خط‌به‌خط، کد تخفیف، تیپ، زمان سرو، محاسبه‌ی امتیاز و ثبت سفارش برای شماره‌ی میز
- **پیگیری زنده‌ی سفارش:** سه مرحله با تایمر واقعی، لغو (برگشت به سبد)، تحویل، امتیاز به سفارش، سفارش مجدد، تاریخچه
- **سرویس میز:** ۸ درخواست (پیشخدمت، فاکتور، ادامه چای، پریز…) با کول‌داون
- **وفاداری:** حلقه‌ی پیشرفت، ۴ سطح با ضریب امتیاز، تبدیل امتیاز به پاداش/کد، دفتر امتیاز
- **پیشنهاد شخصی:** ریسک ریزش محاسبه‌شده از رفتار خودت، ۴ آفر با توضیح «چرا این پیشنهاد»، فعال‌سازی و اعمال کد در سبد، سوییچ یادآوری
- **پروفایل / Customer Passport:** آمار رفتاری، QR میز، خروجی CSV/JSON از داده‌ی خودت، حذف کامل داده
- **گزینه‌های پیشرفته:** تم تاریک/روشن/خودکار، اسلایدر شدت شیشه، فونت بزرگ، کنتراست بالا، حذف انیمیشن، ارقام فارسی/انگلیسی، لرزش، خاموش/روشن‌کردن حالت پیشرفته
- **میان‌برهای کیبورد:** `1..5` برای عوض‌کردن بخش، `Esc` برای بستن منو/شیت — و لینک `mvp.html?table=12#menu` برای شبیه‌سازی اسکن QR هر میز
- فرم تماس با اعتبارسنجی و پیام موفقیت

> ⚠️ **همه‌ی داده‌ها ساختگی است.** اعداد این سایت ادعای نتیجه‌ی واقعی نیستند؛ هدف، نشان دادن
> شکل محصول و تبدیل آن به **ابزار فروش** است.

## قدم بعدی (طبق ۷ Day Startup)

1. این دمو را به ۱۰ تا ۲۰ کافه نشان بده.
2. بپرس: «ماه قبل چند درصد مشتری‌هاتون برگشتند؟» و «برای برگرداندنشان ماهانه پول می‌دید؟»
3. با یک Concierge MVP (گوگل‌شیت + اتوماسیون) اولین کمپین را اجرا کن.
4. عدد را اندازه بگیر: چند نفر هدف، چند نفر برگشت، چند تومان فروش.
5. اگر پول آمد → بساز. اگر نیامد → به‌جای افزودن قابلیت، دلیل «نه» را بفهم.
